# Drifto Beta 页面架构与关系总览

> 本文档定义 Drifto Beta 版本的全局信息架构（IA）、页面状态机以及各页面/抽屉之间的流转关系。
> 采用 **“分步专注架构（Two-Stage Focus Model）”**：纯净对话 $\rightarrow$ 沉浸路线看板 $\rightarrow$ 行中执行。

---

## 二、 核心页面角色与职责索引

| 页面/阶段 | 文档索引 | 核心职责 |
| :--- | :--- | :--- |
| **0. 冷启动引导** | `05_onboarding.md` | 首次进入的 2 步轻量画像收集，初始化算法权重策略。 |
| **1. 极简首页** | `01_homepage.md` | **纯净灵感发起中枢**。快捷需求胶囊 + 紧凑单行输入栏，去除一切环境噪音。 |
| **2. 侧边栏抽屉** | `02_sidebar.md` | **用户与行程资产管理**。用户信息、新建行程、历史行程（含已完成X次成就标记、编辑重命名与删除）。 |
| **3. 阶段一：纯净对话** | `03_planner_page.md` | **意图沟通与追问**。全屏无地图打扰的聊天流，Agent 思考过程与精美路线摘要卡。 |
| **4. 阶段二：路线看板** | `03_planner_page.md` | **成果浏览与微调**。全屏高德地图连线 + 高清图文时间轴 + ActionBar 局部微调。 |
| **5. 阶段三：行中执行** | `03_planner_page.md` | **出行落地闭环**。实时定位距离、高德一键导航、站点逐个打卡与突发事件重排。 |
| **6. 偏好与设置** | `04_profile_settings.md` | **个性化模型控制台**。策略权重滑块（少排队/省钱/口碑）与禁忌标签微调。 |
