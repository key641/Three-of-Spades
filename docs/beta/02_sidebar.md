## 二、 核心三大模块拆解

### 1. 顶部用户与设置区 (User Header)
- **左侧**：用户个性 Emoji/图片头像 + 昵称（如 `若望`）。
- **右侧**：轻量设置图标按钮 `[ ⚙️ ]`，点击跳转或弹出出行偏好与策略设置页（`04_profile_settings.md`）。

### 2. 新建行程行动行 (New Trip Action Bar)
- **整行通栏按钮 `[ ＋ 新建行程 ]`**：
  - 高对比度轻微微光质感。
  - 点击后：收起侧边栏，重置当前会话，回到首页输入框并聚焦，开启全新规划。

### 3. 行程列表与管理模式 (Trip List & Management)
- **标题栏操作**：
  - 左侧展示 `🧭 我的行程` 标题。
  - 右侧提供 `[ 编辑 ✏️ ]` / `[ 完成 ✓ ]` 切换按钮。
- **常规模式 (Normal Mode)**：
  - **正在进行（Active Trip）**：带绿色呼吸灯 `🟢` 与 `[ 进行中 ]` 动态胶囊，点击直接进入行中导航/打卡态。
  - **历史行程（History Trips）**：带 `[ ✓ 已完成X次 ]` 成就标签与日期标签，点击快速查看与一键复用出发。
- **编辑模式 (Edit Mode)**：
  - **重命名操作 (Rename)**：行程标题变为可直接编辑的输入框，或点击铅笔图标原地重命名，失焦或按回车自动保存。
  - **删除操作 (Delete)**：每条行程右侧出现 `[ 🗑️ 删除 ]` 按钮，点击带二次确认弹窗或震动防误触，确认后从本地历史中移除。

## 三、 交互与动效细节

1. **编辑状态平滑过渡**：
   - 点击“编辑”时，列表项优雅展开删除与重命名控件，带微弹簧过渡动画。
2. **滑入/滑出**：
   - 点击首页左上角 `☰` 从屏幕左侧平滑滑出（占屏宽 ~80%）。
   - 点击遮罩区域或左滑手势即刻平滑回弹收起。
3. **列表空状态（Empty State）**：
   - 首次使用尚无行程时，行程列表展示轻量提示：“还没有规划过的行程，快去新建一个吧 ✨”，此时编辑按钮自动隐藏。
