# 前端方案设计文档

> AI 本地路线智能规划 · C 同学负责
> 适配目标：**手机优先，桌面兼容**

---

## 一、核心设计目标

1. **手机可用**：用户在出行途中用手机操作，UI 以 375px 为基准宽度设计，所有核心功能单手可操作。
2. **演示清晰**：评委能一眼看懂 Agent 做了什么、路线为什么合理。
3. **交互闭环**：从输入需求 → 展示路线 → 动态调整 → 提交反馈，在一个页面内完成。
4. **轻量不复杂**：Hackathon 场景，避免过度设计，优先保证演示稳定。

---

## 二、整体布局方案

### 手机端布局（375px～768px）

采用**单列全屏流式布局**，从上到下依次排列各功能区块，通过**底部 Tab 栏**在不同视图间切换：

```
┌─────────────────────────┐
│  顶部标题栏（固定）       │
├─────────────────────────┤
│                         │
│  主内容区（滚动）         │
│  - 聊天输入区            │
│  - AI 回复气泡           │
│  - Agent 思考过程（折叠） │
│  - 路线结果卡片（纵向列表）│
│  - 反馈/重规划按钮        │
│                         │
├─────────────────────────┤
│  底部安全区（iOS 兼容）   │
└─────────────────────────┘
```

### 桌面端布局（≥1024px）

保留原有双栏布局：

```
┌──────────────────────────────────────────┐
│  顶部标题栏                               │
├──────────────────┬───────────────────────┤
│  左侧：对话 + Trace│  右侧：路线结果区      │
│  (1.3fr)         │  (多列横向排列)         │
│                  │                        │
├──────────────────┴───────────────────────┤
│  底部：动态事件 & 反馈（全宽）             │
└──────────────────────────────────────────┘
```

## 三、功能模块设计

### 3.1 顶部标题栏

- **手机**：固定在顶部，高度 56px，居中显示 Logo + 标题"现在就出发"，右侧放用户头像/画像 icon，点击后弹出抽屉展示用户偏好标签。
- **桌面**：与现有方案一致，左侧标题 + 右侧用户画像 Badge。

**字段依赖**：`user_profile`（从 ChatResponse 返回）

---

### 3.2 聊天输入区（ChatPanel）

**交互设计：**

- 输入框在手机上占满宽度，高度自适应（min 3 行），支持换行。
- 发送按钮固定在输入框右下角，使用橙色主色（美团风格），圆形图标按钮。
- 支持快捷短语气泡（Chips）：在输入框上方显示 3～4 个常用需求快捷词，点击自动填充，如：
  - "上海半天 citywalk 2人"
  - "带小孩，亲子友好"
  - "预算200以内，少排队"
  - "今晚吃什么"
- 发送后显示用户消息气泡（右对齐），AI 回复显示为助手气泡（左对齐，绿色背景），两者构成对话流。
- Loading 状态：发送按钮转为 spinner，助手气泡处显示"Agent 思考中…"打字动效（三个点跳动）。

**当前骨架改造点：**
- 将现有 `textarea + button` 改为底部固定输入条（类微信样式）
- 将 `latestMessage` 从独立段落改为消息气泡流

---

### 3.3 Agent 思考过程（AgentTrace）

**手机端：**
- 默认**折叠**，显示"Agent 正在处理…"的进度条动画
- 处理完成后显示"✓ 已完成 N 步"的摘要，点击展开查看详情
- 展开后以**步骤卡片**形式纵向排列，每步显示：
  - 步骤图标（不同步骤用不同 emoji / icon 区分）
  - 步骤标签（如"LLM 解析用户意图"）
  - 状态标记（done / fallback / error，用颜色区分：绿/橙/红）

**桌面端：**
- 保持侧边栏常驻展示，无需折叠

**步骤图标映射：**

| step | 图标 | 说明 |
|------|------|------|
| `parse_intent` | 🧠 | 理解意图 |
| `get_user_profile` | 👤 | 读取画像 |
| `build_strategy_weights` | ⚖️ | 生成权重 |
| `search_pois` | 📍 | 召回地点 |
| `generate_routes` | 🗺️ | 规划路线 |
| `summarize_routes` | ✍️ | 生成总结 |
| `direct_llm_chat` | 💬 | 直接对话 |

**字段依赖**：`agent_trace[]` → `step / label / status`

---

### 3.4 路线结果区（RouteCompare + RouteCard）

这是最核心的展示区域，需要让用户**一眼看懂三条路线的差异**。

**手机端——横向滑动卡片：**

```
←  [方案A：美食优先] [方案B：少排队] [方案C：省钱版]  →
         ●  ○  ○
```

- 三张路线卡片横向排列，支持**左右滑动切换**（swipe 手势）
- 底部小圆点指示当前位置
- 每张卡片高度固定（约 60vh），内部可纵向滚动

**桌面端——三列并排：**
- 保持现有 `grid-template-columns: repeat(3, 1fr)` 三列布局

**路线卡片内容（RouteCard）：**

```
┌──────────────────────────────┐
│  🗺️ 方案A：美食优先      [8.5]│  ← 标题 + 综合评分
│  "适合3人朋友，主打本帮菜"    │  ← 一句话摘要
├──────────────────────────────┤
│  ⏱ 280分钟  💰 人均¥135  ⏳15分钟│  ← 核心指标横排
├──────────────────────────────┤
│  行程时间线：                 │
│  ┃ 14:00  武康路街区          │
│  ┃        citywalk · 80分钟   │
│  ┃ 15:30  安静咖啡馆          │
│  ┃        咖啡 · ¥45 · 排队5分│
│  ┃ 16:30  弄堂本帮菜          │
│  ┃        餐厅 · ¥135 · 排队20分│
├──────────────────────────────┤
│  推荐原因：                   │
│  [评分高] [少排队] [本帮菜]   │  ← 标签 chips
├──────────────────────────────┤
│  [换一家] [更省钱] [少排队] [亲子] │
└──────────────────────────────┘
```

**评分维度可视化（score_breakdown）：**
- 在卡片内用 5 条迷你进度条展示：品质 / 排队 / 预算 / 距离 / 偏好匹配
- 每条进度条宽度 = 对应分数 / 10

**字段依赖**：
- `route.title / summary / score / total_duration_minutes / total_cost_per_person / total_queue_minutes`
- `route.score_breakdown.quality / queue / budget / distance / preference`
- `route.stops[].name / category / start_time / end_time / estimated_cost / queue_minutes`
- `route.reasons[]`

---

### 3.5 交互操作栏（ActionBar）

- 每张路线卡底部放置 4 个快捷操作按钮
- 手机上按钮改为**全宽圆角行**，每行 2 个，更易点击（min-height 44px）
- 按钮点击后发送对应指令给 `/api/chat`（如"把第一条路线的餐厅换成更便宜的"）

| 按钮 | 发送消息 | 图标 |
|------|---------|------|
| 换一家 | "帮我替换掉第 N 个地点" | 🔄 |
| 更省钱 | "重新规划，降低预算" | 💰 |
| 少排队 | "重新规划，避开排队" | ⏩ |
| 亲子友好 | "加入亲子友好筛选条件" | 🧒 |

---

### 3.6 动态事件重规划（ReplanPanel）

**手机端：**
- 以**底部抽屉（Drawer）**形式呈现，点击"模拟突发事件"按钮展开
- 展开后显示三个事件按钮（餐厅排队 90 分钟 / 交通堵车 / 有点累了）
- 点击后展示"重规划中…"过渡动画，然后替换路线卡片并显示变更说明

**重规划变更提示：**
```
⚠️ 已重规划：餐厅排队 90 分钟
   第 2 站「弄堂本帮菜」→「外滩快餐」（节省 75 分钟等候）
```

**字段依赖**：`route.replan_reason`（重规划时后端返回）

---

### 3.7 反馈收集（FeedbackPanel）

**手机端：**
- 路线完成后以**全屏弹窗（Modal）**形式展示，或放在页面底部可展开区块
- 简化为 5 个评分项，用**表情 + 星级**双重选择（比 input 更适合手机）：

```
这次行程怎么样？

📍 路线合理性    ★★★★☆
🍽️ 餐厅满意度    ★★★★★
⏱️ 时间安排      ★★★☆☆
💰 预算控制      ★★★★☆
🤖 AI 准确度     ★★★★☆

[提交反馈]
```

- 提交后调用 `/api/feedback`，并显示"感谢反馈，已更新你的偏好档案"

## 四、样式风格

### 4.1 设计语言

参考**美团 App 风格** + **现代简洁 Card UI**：

- 圆角卡片为主（border-radius: 12px），层次清晰
- 功能区间用浅灰背景（`#f6f7f9`）分隔，卡片白色背景（`#ffffff`）
- 强调色使用**美团橙 `#FF6600`**，用于：主按钮、评分高亮、重要数字
- 辅助色使用**深绿 `#1A8A5A`**（来自现有 `.assistant-message` 背景 `#eef6f3`），用于 AI 回复气泡背景
- 文字：主色 `#20242a`，次要 `#66707c`，禁用 `#b0b6be`

### 4.2 字体与尺寸

```css
/* 手机端字体大小规范 */
--font-title:    20px;  /* 页面标题 */
--font-heading:  16px;  /* 卡片标题 */
--font-body:     14px;  /* 正文 */
--font-small:    12px;  /* 标签/辅助文字 */

/* 间距 */
--space-xs:  4px;
--space-sm:  8px;
--space-md:  12px;
--space-lg:  16px;
--space-xl:  24px;
```

### 4.3 颜色系统

```css
--color-primary:     #FF6600;  /* 美团橙，主按钮 */
--color-primary-bg:  #FFF3EB;  /* 橙色浅底 */
--color-ai-bg:       #EEF6F3;  /* AI 回复绿色背景 */
--color-success:     #12B76A;  /* 完成/done */
--color-warning:     #F79009;  /* fallback/注意 */
--color-error:       #B42318;  /* error/失败 */
--color-bg:          #F6F7F9;  /* 页面底色 */
--color-card:        #FFFFFF;  /* 卡片背景 */
--color-border:      #E0E4EA;  /* 边框 */
--color-score-bg:    #12212F;  /* 评分深色背景 */
```

### 4.4 交互动效

- 按钮：hover 变浅橙色，active 下压效果（transform: scale(0.97)）
- 路线卡片加载：skeleton 占位骨架屏，比 loading spinner 体验更好
- Agent Trace：步骤逐个淡入（staggered animation，每步延迟 100ms）
- 卡片切换：横滑时有轻微的弹性回弹效果
- 错误信息：顶部 Toast 提示，3 秒后自动消失

## 六、手机适配关键清单

| 项目 | 要求 | 实现方式 |
|------|------|---------|
| 触摸目标尺寸 | 所有可点击元素 ≥ 44×44px | `min-height: 44px` |
| 滚动区域 | 路线卡片内可独立滚动 | `overflow-y: auto` + `-webkit-overflow-scrolling: touch` |
| 横向滑动 | 路线卡片左右滑动 | CSS scroll-snap 或轻量 swipe hook |
| iOS 底部安全区 | 底部导航不被 Home 条遮挡 | `padding-bottom: env(safe-area-inset-bottom)` |
| 软键盘处理 | 输入框获焦时页面不错位 | 输入区固定底部，内容区留出空间 |
| 字体缩放 | 禁止 iOS 自动放大文字 | `-webkit-text-size-adjust: 100%` |
| 点击延迟 | 消除 300ms 点击延迟 | `touch-action: manipulation` |
| 暗黑模式 | 暂不支持（Hackathon 阶段） | 固定 light 模式 |

## 八、第一周交付目标（对齐 README）

```
1. 手机输入一句话 → 展示路线卡片 + Agent Trace（可折叠）
```
